Hook refusal evidence — 2026-09-06
==================================

Setup: PreToolUse hook in .claude/settings.local.json, matcher "Write|Edit",
protecting the legacy/ directory (this repo's migration rollback artifact —
chosen over the exercise's .env example because frontend/.env is a file the
build legitimately writes).

Hook command:
  jq -e '.tool_input.file_path // "" | test("/legacy/") | not' >/dev/null \
    || { echo 'refused: legacy/ is the migration rollback artifact — read-only forever' >&2; exit 2; }

Action: Claude attempted
  Write /Users/chewan/Desktop/TODO/legacy/hook-refusal-probe.txt

Terminal output (verbatim tool error returned to Claude):

  PreToolUse:Write hook error: [jq -e '.tool_input.file_path // "" | test("/legacy/") | not' >/dev/null || { echo 'refused: legacy/ is the migration rollback artifact — read-only forever' >&2; exit 2; }]: refused: legacy/ is the migration rollback artifact — read-only forever

Result: exit code 2 blocked the Write BEFORE it executed. The file
legacy/hook-refusal-probe.txt was never created (verified with ls).
The PostToolUse log hook recorded nothing for this call — it never got
past PreToolUse, which is precisely the difference between a hook that
watches (PostToolUse: the write would already be on disk, this would be
a log line) and a hook that stops (PreToolUse exit 2: the work never runs).
